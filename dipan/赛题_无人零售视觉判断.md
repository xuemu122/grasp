# 赛题：无人零售视觉判断模型

## 一、赛题背景

在无人零售场景中，智能机器人需要自主判断货架上摆放了哪些商品、每个商品在什么位置、与摄像头距离多远。通过将算法判断结果与真实情况对比，来衡量视觉判断模型的准确性和可靠性。

## 二、核心任务

**判断依据 = 商品类别 + 货架位置 + 摄像头距离**

给定 RGB-D 相机拍摄的货架图像，参赛者需要回答以下三个问题：

| 问题 | 输出 | 示例 |
|------|------|------|
| 货架上有什么？ | 商品类别标签 | "ydk"、"阿莫西林" |
| 商品在第几层？ | 货架层位编号 | S01 货架 第 2 层 |
| 离摄像头多远？ | 深度值（米） | 0.42m |

**通过反馈结果判断算法好坏：** 将算法输出与人工标注的真实值（ground truth）逐一比对，统计正确/错误数量，计算准确率。

## 三、输入

| 输入项 | 格式 | 说明 |
|--------|------|------|
| RGB 图像 | 640×480 BGR | RealSense D405 采集 |
| 深度图 | 640×480 uint16 | 每像素深度值 |
| 相机内参 | fx, fy, cx, cy | 实际读取或标定值 |
| 手眼矩阵 | T_flange→camera (4×4) | 相机在法兰坐标系下的位姿 |
| 商品映射表 | YAML | 类别名 → 货架编号+层数 |
| YOLO 权重 | .pt | 检测模型 |

## 四、输出

每个检测到的商品输出：

| 字段 | 类型 | 说明 |
|------|------|------|
| class_name | str | 商品类别 |
| bbox | (x1,y1,x2,y2) | 像素坐标系边界框 |
| depth_m | float | 目标区域中位数深度（米） |
| shelf_id | str | 货架编号 |
| layer | int | 层数 |
| camera_xyz | (x, y, z) | 相机坐标系 3D 坐标（米） |
| world_xyz | (x, y, z) | 机器人基座坐标系 3D 坐标（米） |

## 五、评测方式

### 5.1 反馈判断逻辑

对每张测试图像，对比算法输出和人工标注结果：

```
逐一比对每个商品:
  ✓ 类别正确?        → 商品识别准确
  ✓ 货架层位正确?    → 空间定位准确
  ✓ 深度误差 ≤ 5cm?  → 距离估计准确
  ✗ 以上任一不满足   → 标记为判断错误
```

### 5.2 评分标准

| 评价维度 | 权重 | 判断标准 | 计算方式 |
|----------|------|---------|---------|
| 商品检出率 | 30% | 货架上有什么 | 被检测到的商品数 / 实际商品总数 |
| 分类准确率 | 20% | 商品类别对不对 | 正确分类数 / 检测总数 |
| 距离准确率 | 25% | 离摄像头多远 | 深度误差 ≤ 5cm 的检测数 / 总检测数 |
| 层位准确率 | 15% | 第几层 | 层数正确数 / 检测总数 |
| 3D 定位精度 | 10% | 绝对空间位置 | 欧氏距离 ≤ 10cm 的检测数 / 总检测数 |

**总分 = Σ(各维度得分 × 权重)**，满分 100 分。

### 5.3 评级标准

| 总分 | 等级 | 说明 |
|------|------|------|
| ≥ 90 | 优 | 算法可实际部署 |
| 80-89 | 良 | 核心功能完备，细节需优化 |
| 70-79 | 中 | 基本可用，存在明显短板 |
| 60-69 | 及格 | 能跑通 pipeline，需较大改进 |
| < 60 | 差 | 算法不可用 |

## 六、技术要点

1. **深度滤波**：剔除 0 值及超范围值（<0.05m 或 >3m），用中位数抗噪声
2. **深度尺度**：从 SDK 读取 `depth_scale`，不要硬编码 `/1000`
3. **手眼变换**：注意法兰坐标系方向（X=手背, Y=手宽, Z=手指），旋转顺序 X→Y→Z
4. **拍照策略**：丢弃前 5 帧等自动曝光稳定，多帧中按光照评分择优
5. **像素→3D 反投影**：`x = (u-cx)*depth/fx, y = (v-cy)*depth/fy, z = depth`

## 七、提交要求

1. 可运行的 Python 推理脚本
2. 测试集输出 JSON（含 `class_name`、`depth_m`、`shelf_id`、`layer`、`world_xyz` 等字段）
3. 技术报告（含流程图、关键公式、模型选择说明、错误案例分析）
