# 识别 — 视觉识别模块

YOLO 目标检测 + EasyOCR 文字识别 + RealSense D405 深度相机，用于货架药品盒子的实时检测与定位。

## 文件

| 文件 | 说明 |
|------|------|
| `orbbec_detect.py` | **主程序**: 实时检测 + OCR + 3D坐标 + 光照评估 + 反光检测 |
| `best.pt` | YOLO 模型权重 (药品检测) |
| `shelf_mapping.yaml` | 药品-货架位置映射表 |
| `requirements.txt` | Python 依赖列表 |
| `run.sh` | 启动脚本 (Gemini Pro 相机) |
| `madata.yaml` | 数据集配置 |

## 主程序: orbbec_detect.py

### 功能

- **YOLO 实时检测**: 640x480 画面逐帧推理，识别药盒 (ths / ydk 等类别)
- **EasyOCR 中文识别**: 逐框裁剪 + 2x 放大，识别药盒标签上的中文药品名
- **RealSense 深度**: 自动读取相机内参，像素 → 相机三维坐标
- **光照评估**: HSV 分析 + 反光检测，光线差时告警
- **画面交互**: 鼠标点击选中目标，按 `s` 截图保存 JSON 结果

### 启动

```bash
cd /home/nvidia/grasp/识别
python3 orbbec_detect.py
```

### 操作

| 按键 | 功能 |
|------|------|
| 鼠标点击 | 选中 / 取消选中检测框 |
| `s` | 截图 + 保存 JSON 检测结果到 `results/` |
| `q` | 退出 |

### 坐标说明

`camera_xyz` 为相机坐标系三维坐标 (米): X 右、Y 下、Z 前 (光轴方向)。
